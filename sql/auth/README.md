# Auth 数据库脚本

本目录只管理 `smile-auth-service` 独占数据库。Auth 拥有凭证摘要、密码历史、已验证手机号、验证码挑战、激活重置、设备会话和 Auth 审计，不得创建或访问 IAM 业务表。

- `ddl/`：sequence、表、索引、约束及结构变更。
- `dml/`：经过确认的安全策略初始化数据和受控数据修正。

密码摘要、验证码、恢复码、Token、HMAC 密钥、手机号密文和 Pepper 均不得以初始化 DML 形式提交仓库。

短信供应商、短信模板以及激活/重置链接地址由平台超级管理员通过平台端维护，数据库只提供配置结构，不使用 DML 写入真实配置。供应商密钥加密落库且接口不回显明文；用于加密它的根密钥、数据库密码和服务间 HMAC 密钥仍只能来自环境变量或密钥服务。
